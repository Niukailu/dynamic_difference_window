# 无损隐式矩阵与 25 轮搜索（2026-09-21）

本轮仍使用共享 B300，没有停止训练任务或申请独占。重点是 SIMON64 线性 25 轮，物理输入 `(0x44400, 0x1000)`，输出 `(0x1000, 0x44400)`。结果是论文模型下平方相关路径的聚集权重，不是固定密钥有符号相关性的实测，也不是完整密钥恢复攻击。

## 让宽窗口装入显存

之前每轮生成完整 FP64 矩阵。现在保存前一轮的陪集聚合值、每列秩、偏移和仿射查找表，用它们随时重建矩阵元素：

`P(t,l) = coset_sum[offset[l] + affine_key(t,l)] × 2^(-rank[l]) × normalization`

不满足仿射约束时该元素为零。这是原转移输出的无损表示，没有降为 FP32，也没有按阈值删掉小概率项。下一轮直接读取虚拟元素并归约成新的陪集；无需生成整张矩阵。统计阶段同时缓存每行与每个位的边缘质量，供下一轮选窗复用。

| 完成的单卡实验 | 最大稠密单状态 | 最大实际单状态表示 | 25 轮计算时间 |
|---|---:|---:|---:|
| w18，从后验优化 w14 扩展 | 512 GiB | 5.36 GiB | 157.55 s |
| w19，从原 w17 嵌套扩展 | 2 TiB | 13.80 GiB | 633.82 s |

这里统计的是**单状态**，不含同时存活的前后状态、工作区和 CUDA 上下文；实验预算为每进程 50 GiB。上述两次运行中 w19 尚未融合边缘统计缓存，最终代码的缓存另外占用少量显存。计时来自共享 GPU，不作独占吞吐或跨负载速度比较。

它主要解决显存瓶颈：计算仍需遍历大量虚拟元素，复杂度没有从 `O(4^w)` 变成多项式。宽度 20 仍是当前索引/陪集实现的上限；该后端目前单卡运行，与原有稠密多卡后端并存。

## 用最终端点评价所有单比特替换

`refine --strategy posterior` 将当前窗口临时增加一个自由位。在扩大后的状态上计算前向权重 `F(t,l)` 与反向端点权重 `H(t,l)`。对 `F×H` 按每个自由位的 0/1 两半归约，就能得到该扩大窗口内全部单比特替换的精确最终端点分数，包括固定基底位翻转。

每个候选只在目标坐标上施加一次限制；下一状态中重复出现的同一坐标由 Feistel 转移保持，因此没有重复计数。两个半空间分别累加，避免用“总量减小量”造成消减误差。每次扩大还核对原窗口的后验分数与独立三轮重放分数；每个 sweep 检查目标概率不下降。

w14 的完整 25 轮从 **−64.308345167727** 改善到 **−64.263484114764**，约增加 3.16% 权重。原计划和对称拼接计划这两个起点都收敛到相同分数；这不是全局最优保证。

## 当前概率结果

| 路径集合 | log₂ 权重 |
|---|---:|
| 本轮之前的最佳反射并集 | −64.134564031949 |
| 后验 w14 → w18，单窗口计划 | −64.141634536717 |
| 上述 w18 与其反射的去重并集 | −64.121868999726 |
| 原 w17 → w19，单窗口计划 | −64.147072682883 |
| 上述 w19 与其反射的去重并集 | −64.109460619010 |
| 前 12 轮与其反射拼接的 w18 计划 | −64.125233668596 |
| w18/w19 两条扩展路线及各自反射的四集合并集 | −64.107703325526 |
| w19 及其反射，再并入对称 w18 计划（本轮最好） | **−64.105767763312** |

本轮最佳比之前提高约 **2.02%**，距离 −64 阈值从 0.13456 bit 缩小到 **0.10577 bit**；还需要约 **7.61%** 的额外权重才能跨过阈值，**没有增加有效区分器轮数**。[最佳并集及全部容斥项](../results/best/simon64-linear25-implicit-union.json)保留了各个交集的独立记录。

单个更宽窗口并不保证优于来自另一搜索历史的窄窗口。因此保留两条扩展路线，再用精确容斥合并它们，而不是直接相加概率。反射成立的原因是转移核只依赖中间左分支 `l` 和 `t XOR r`，在交换输入/输出端点的条件下路径权重不变。

此外完成了输入的 65 个旋转规范化单比特邻域候选的 w12 搜索，未发现比原输入更好的峰值。部分输入的首轮分布等价，得到相同分数；低宽度筛选不能排除其他输入在大宽度下更强。原始记录见 `results/exploration/neighbor-scan-w12/`。

## 使用

```bash
# 从原有 w17 计划扩到 w19；只跑参考的前 25 轮
./target/release/ddw compressed \
  results/exploration/simon64-linear26-refined-w17.jsonl \
  --width 19 --rounds 25 --device 0 --memory-gib 50 \
  --output results/my-implicit19.jsonl

# 单卡后验选窗；扩大一位所需工作区高于普通端点优化
./target/release/ddw refine \
  results/exploration/simon64-linear25-refined-w14.jsonl \
  --strategy posterior --device 0 --memory-gib 40 \
  --host-memory-gib 128 --passes 3 --output results/my-posterior.jsonl

# 固定前 12 轮，与反射拼接为 25 轮；用隐式状态重放
./target/release/ddw mirror results/my-implicit19.jsonl \
  --half-rounds 12 --compressed --devices 0 --memory-gib 40 \
  --output results/my-mirror.jsonl

# 单计划 + 反射：2P(A)-P(A∩reflection(A))
./target/release/ddw symmetric-union results/my-implicit19.jsonl \
  --device 0 --memory-gib 40 --output results/my-union.json

# 两个计划及各自反射，最多四集合；包含全部高阶交集
./target/release/ddw path-union results/my-implicit19.jsonl results/my-mirror.jsonl \
  --reflect --device 0 --memory-gib 40 --output results/my-four-way.json
```

`compressed` 输出完整 JSONL，拒绝覆盖文件；`validate` 检查完整性、质量单调性和参考端点不下降。并集命令要求相同输入、轮数和交换端点，输出 JSON 汇总及各交集的独立 JSONL。空交集显式记录为零概率。镜像计划可能没有可达路径，此时重放明确失败。

## 验证

- 20 种字长/密码/模式组合的 5 轮逐元素对照：隐式矩阵重建与稠密 FP64 一致，同时核对峰值、质量和 argmax。
- SIMON/SIMECK × 差分/线性的后验半空间分数，与每个候选的独立完整局部重放比较；覆盖终点前零、一、二步以及更长后缀。
- Rust CLI 的镜像、后验优化和隐式扩窗由独立 CPU 转移逐轮核对；重复路径集合的容斥结果保持不变。
- 旧 w17 反射并集由新的 Rust 隐式引擎复核，仍为 **−64.134564031949**，与此前实现一致。

大宽度结果采用 FP64，未使用严格区间算术。新后端的验证不意味着已经独立实测真实密码的 25 轮有符号相关性。

最终检查：Rust 3 项普通测试、3 项显式 GPU 测试和 Python 25 项交叉测试全部通过。所有本轮新增完整 JSONL 通过独立日志检查；两份四集合结果另外用 Python `math.fsum` 重新计算容斥和，误差为零或浮点舍入量级。汇总见[验证记录](../results/validation/implicit-research-checks.json)与[容斥审计](../results/validation/implicit-union-audit.json)。
