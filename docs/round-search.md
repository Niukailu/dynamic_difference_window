# 增加轮数的后续探索

当前最佳：SIMON128 差分 45 轮为 **−127.442713104012**；SIMON64 线性 25 轮路径并集为 **−64.088105604252**，仍未越过 −64。最新跨轮选窗与新增路径实验见[本轮记录](cross-round-search.md)，此前非均匀选窗见[选窗实验](window-selection.md)。以下保留早期探索记录。

以下均为共享 B300 上的论文路径聚集模型结果，不宣称新公开纪录。原始记录见 `results/exploration/`。

| 尝试 | log₂ 权重 | 判断 |
|---|---:|---|
| SIMON128 差分，最佳 w17 前缀继续至 46 轮 | −134.475496384 | 距 2^-128 约 6.48 bit |
| SIMON128 线性，46 轮端点优化 w14 | −131.526181016434 | 未超过 2^-128 |
| SIMON64 线性，25 轮端点优化 w14 | −64.308345167727 | 未超过 2^-64 |
| 上述计划扩展至 w17，25 轮 | −64.169472987480 | 未超过 2^-64 |
| w17 计划及其反射路径集合的精确并集，25 轮 | −64.134564031949 | 仍差约 0.13456 bit |

反射并集仅在端点满足交换对称时使用。交集通过逐轮窗口交集计算，采用 `P(A∪B)=P(A)+P(B)−P(A∩B)`，没有将重复路径计算两遍；四集合容斥试验没有增加保留路径的总权重。小字长 CPU 路径穷举用于检验这一算法。

还对参考端点及其交换产生的 22 个旋转规范化输入进行了 w12 扫描；差分 46 轮和线性 25 轮都未突破阈值。低宽度筛选不能排除其他输入在大宽度下更优。

下一步最接近阈值的是 SIMON64 线性 25 轮：可探索不同窗口历史的互补路径集合、联合端点与输入优化，以及更长程候选搜索。应继续按相同端点检查重叠与概率，避免把不同束的权重直接相加。

后续 Rust 无损隐式矩阵实验已推进到单卡 w19；后验选窗、扩窗与同端点路径并集把当前最佳改进为 **−64.105767763312**，仍未越过 −64。详见[实现、实验与验证](implicit-search.md)。
